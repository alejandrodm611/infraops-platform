# Infraops Platform
## Readme

Laboratorio personal de Cloud & DevOps.

## Objetivo

Construir progresivamente una plataforma de infraestructura reproducible,
automatizada y monitorizada utilizando tecnologías y prácticas utilizadas
en entornos profesionales.

## Tecnologías

Las tecnologías se incorporarán progresivamente durante el desarrollo:

- Git & GitHub
- Linux
- Docker
- Azure
- Terraform
- Ansible
- GitHub Actions
- Kubernetes
- Helm
- Prometheus
- Grafana
- ArgoCD

## Arquitectura

La arquitectura evolucionará durante el proyecto a medida que se incorporen
nuevas tecnologías y componentes.

## Roadmap

- [ ] Fundamentos Linux y Git
- [ ] Containerización con Docker
- [ ] Infraestructura en Azure
- [ ] Infrastructure as Code con Terraform
- [ ] Automatización con Ansible
- [ ] CI/CD con GitHub Actions
- [ ] Kubernetes
- [ ] Observabilidad
- [ ] GitOps
- [ ] Seguridad
- [ ] Disaster Recovery
- [ ] Proyecto final

## Objetivo final

Crear una plataforma capaz de desplegar y mantener una aplicación mediante
procesos automatizados, reproducibles y observables.
